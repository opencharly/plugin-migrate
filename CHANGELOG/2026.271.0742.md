# 2026.271.0742 — fix(migrate): write rollback backups to a gitignored dir (never pollute git status)

## Summary

`charly migrate` wrote a `<file>.bak.<unix-ts>` rollback copy **adjacent** to every file it rewrote (`candy/plugin-migrate/engine.go` — `stripVersionField` and the node-form `rewriteDocFile`). Across the schema-versioning-removal corpus those backups landed as untracked files beside the migrated manifests and were `git add`-ed into commits on **plugin-box#19, plugin-deploy-local#11 and plugin-deploy-vm#31**, blocking all three. The `charly` repo and this repo carry `*.bak`/`*.bak.*` in `.gitignore`; most plugin repos do not, so the fix cannot be a per-repo `.gitignore` edit.

Both call sites now go through **ONE** helper, `writeMigrationBackup(root, path, data)`, which keys every rollback copy under the migrate root's gitignored tree:

```
<root>/.charly/backups/<relpath-from-root>.<unix-ts>
```

The helper idempotently installs `<root>/.charly/.gitignore` containing a bare `*`, so the ENTIRE `.charly/` tree (including the inner `.gitignore`) is ignored and `git status` shows **nothing** for it — in ANY repo, with **no** per-repo `.gitignore` edit. The backup path is printed (`backup: …`) so rollback stays discoverable. Backups stay **local to the tree they protect** (never an XDG cache). A path outside root (the per-host overlay at `~/.config/charly/charly.yml`) is re-keyed under `external/` so it can never escape the backup tree via `..`.

Diff: **4 files, +425/−22**.

- `candy/plugin-migrate/engine.go` — new `writeMigrationBackup` + `migrationStateDir`/`migrationGitignore` consts; `stripVersionField`, `runDocMigration` and `rewriteDocFile` take `(root, …, out)` and route every backup through the helper. The whole-second stamp became nanoseconds because one run rewrites a file in more than one step and a same-second stamp silently clobbered the pre-migration snapshot.
- `candy/plugin-migrate/engine_test.go` — the new backup-behavior tests (below).
- `charly.yml` — adds one deterministic R10 check step (`migrate-backup-gitignored`).
- `.gitignore` — removes the now-dead `*.bak`/`*.bak.*` block (the engine no longer writes adjacent backups; R5 stale-claim sweep).
