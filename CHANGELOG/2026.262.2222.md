# 2026.262.2222 — feat(migrate): cpus->cpu deploy-override rename, path-scoped

## Summary of changes

The `cpus:` → `cpu:` migration for the per-deploy VM-shape override cutover (sibling of `opencharly/spec#137`, now MERGED + tagged `v0.2026262.1825`).

The spec leg renames `#Deploy`'s CPU field from the outlier plural `cpus:` to the singular `cpu:` (matching `#Vm`). This leg gives `charly migrate` the matching transform.

Concrete edits (8 files, +354/−34):

- `candy/plugin-migrate/reshape_deploy_cpu.go` (new) — `reshapeDeployCPU`, a **path-scoped reshaper hook** renaming a substrate kind body's own direct `cpus:` → `cpu:`. A dedicated `deploySubstrateWords` set covers pod/vm/k8s/**kubernetes**/local/android (the generic `reshapeKindWords` set lacks `kubernetes`, and the k8s→kubernetes migration runs BEFORE this row — so the dedicated set is required).
- `candy/plugin-migrate/engine.go` — registers `reshapeDeployCPU` in `goHooks`.
- `candy/plugin-migrate/migrations.cue` — the `deploy-cpu-spelling` row at `2026.261.1747`.
- `candy/plugin-migrate/reshape_deploy_cpu_test.go` (new) — **6** tests: basic rename, the `security.cpus` NON-collision (direct + nested), all five substrate kinds, idempotency, the both-keys case.
- `candy/plugin-migrate/go.mod` / `go.sum` — adopt `spec v0.2026262.1825` (the tagged cutover head, `#SchemaVersion` `2026.261.1747`) + the lockstep `sdk v0.2026262.1218` (which retires the pre-cutover `spec.FleetNode` alias, so the module builds against the new spec).
- `engine_test.go`, `reshape_group_deploy_test.go` — the two positional table tests updated (count 10; the newest row pinned at head).

**Why a reshaper hook, not a `rename_key` op** — the load-bearing design choice. `{op: rename_key, from: cpus, to: cpu, under_kind: vm}` is **unsafe**: the op-walker's `under_kind` marks every mapping nested *within* the entity, so it would also rewrite a LIVE `security: {cpus: "2.5"}` string quota into the schema-invalid `security: {cpu: "2.5"}`. A short key word needs the exact PATH, which the hook targets (the `reshapeGraphicsGL` precedent). `TestDeployCPUDoesNotTouchSecurityCpus` fails if the direct-child guard is removed.
