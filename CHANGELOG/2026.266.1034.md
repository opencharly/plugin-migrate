# 2026.266.1034 — feat: relocate the migrate R10 witness bed from opencharly/charly

## Summary of changes

Relocate the `check-migrate-local` R10 witness bed and its `check-migrate-app` `kind:local` template out of `opencharly/charly`'s `charly.yml` and into the plugin's owning repo. A check bed must live in the repo that owns what it tests: the check-bed runner's dev-tree override (`proc.SelfSuperprojectOverridePair`, `spec/proc/repo_override.go`) points the bed project's own superproject's `@github` refs at the local tree, and in the umbrella every submodule's superproject is `opencharly/opencharly` (which hosts no candies) — so a plugin candy owned by another repo was never exercised as in-development code while its witness sat in `charly`. Relocated here, the template composes the LOCAL `plugin-migrate` candy with no `@github` pin.

- `charly.yml` — adds the `check-migrate-app` `kind:local` template (composing the LOCAL `plugin-migrate` candy) and the `check-migrate-local` disposable R10 bed (`host: local`, `lifecycle: dev`) with its three live `charly migrate` checks (at-HEAD no-op, `--dry-run` plumbing, below-floor refusal); migrates the project `version:` stamp `2026.232.0520` → `2026.249.2125` (the schema head); sweeps the now-false "declares no entities of its own" header comment.
- `.gitignore` — new file: the standard generated-artifact rules (`.build/`, `.containerignore`, `.dockerignore`, `.check/`, `output/`, editor scratch, and the `*.bak`/`*.bak.*` migration rollback backups `charly migrate` writes), appended below any existing entries.
- `.github/workflows/deploy.yml` — bumps the CI-pinned charly source `v2026.238.1242` → `v2026.256.1316`. The stamp `2026.249.2125` is NEWER than the old pin's schema head (`2026.232.0520`, verified at the pinned spec `v0.2026232.521-0.20260826090151-ce44afab8bbf`), so the old pinned charly would refuse it ("schema … is newer than this charly supports"); `v2026.256.1316` carries schema head `2026.249.2125` exactly (verified at spec `v0.2026256.653`), so the pinned CI `charly box validate` accepts the stamp.
